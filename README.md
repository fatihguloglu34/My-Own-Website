## 📌 Genel Bakış

Bu repo; modern, sade, erişilebilir ve yüksek performanslı **kişisel portfolyo sitemin** kaynak kodlarını içermektedir. Harici ağır kütüphaneler veya framework'ler kullanılmadan, tamamen **vanilla web teknolojileriyle** hazırlanmış, ultra hafif ve hızlı yüklenecek şekilde tasarlanmıştır.

### ✨ Öne Çıkan Özellikler

* **🎨 Koyu / Açık Tema (Dark/Light Mode):** Sistem temasını (`prefers-color-scheme`) otomatik algılar ve sağ alttaki butonla anlık geçiş imkanı sunar.
* **⚡ Sıfır Bağımlılık (Zero Dependency):** Saf HTML5, CSS3 ve Vanilla JavaScript; anında yüklenme süresi.
* **📱 Tam Responsive Yapı:** CSS Grid ve Flexbox altyapısıyla mobilden geniş ekranlara kadar kusursuz uyum.
* **📐 Sheet / Veri Tablosu Görünümü:** Hero alanında grid temalı kompakt özet kartı.
* **♿ Erişilebilirlik ve Akıcı Gezinme:** `aria-label` yapılandırmaları ve pürüzsüz kaydırma (`smooth scroll`).

## 🛠️ Kullanılan Teknolojiler

| Alan | Teknoloji | Açıklama |
| :--- | :--- | :--- |
| **İskelet** | HTML5 | Semantik etiketler (`<header>`, `<section>`, `<article>`, `<footer>`) |
| **Stil & Tasarım** | CSS3 | CSS Değişkenleri (`var(--...)`), Grid, Flexbox, Media Queries |
| **Etkileşim** | Vanilla JavaScript | DOM manipülasyonu ve tema durumu yönetimi |
| **Tipografi** | Google Fonts | *Bricolage Grotesque* & *IBM Plex Sans* |
| **Dağıtım** | GitHub Pages | Otomatik ve ücretsiz barındırma altyapısı |
